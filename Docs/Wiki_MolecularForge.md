# MolecularForge — Protein & Molecule Visualization from PDB, mmCIF & AlphaFold

Load real protein structures into Unreal Engine 5.8 and render them five ways — space-filling, ball-and-stick, backbone, cartoon ribbon and Gaussian surface — switchable at runtime on a single actor.

Science and education projects in Unreal usually stop at the first hurdle: there is no way to get a real structure into the engine. You export a mesh from PyMOL, lose every atom identity on the way, and end up with a prop instead of a model. MolecularForge reads the archive formats directly — fixed-column PDB and token-based mmCIF — keeps element, residue, chain and B-factor for every atom, and builds the geometry in the engine. What you get is a structure you can select into, measure, colour by any scheme and animate, not a static mesh.

## Key Features

- **Five representations**, switchable on one actor: space-filling, ball-and-stick, backbone, cartoon ribbon with helix/sheet/coil profiles, and a Gaussian surface built by marching tetrahedra.
- **Reads PDB and mmCIF** — the same entry in both formats parses to the same atoms, and an automated test checks exactly that, atom by atom.
- **Downloads structures** from the RCSB Protein Data Bank and from the AlphaFold database, with an on-disk cache and a background parse that does not stall the game thread. AlphaFold models are recognised and carry their CC-BY attribution string with them.
- **Secondary structure** computed in the engine after Kabsch & Sander (1983) — hydrogen bonds, n-turns and bridges — or taken from the file's own HELIX/SHEET records.
- **Selection language** in the style of PyMOL: `chain A and resi 10-25 and not name CA`, parsed by recursive descent, usable from Blueprint.
- **Measurements**: distance, angle and dihedral with the IUPAC sign convention.
- **DCD trajectory playback** with frame interpolation — both byte orders, and files with fixed atoms are rejected rather than silently mis-read.
- **Mesoscale crowding** on Unreal's Mass framework: molecules as entities, Brownian diffusion with reflecting or wrapping bounds, association and dissociation with per-second rates, and distance-staggered drawing.
- **Niagara handoff** — atom positions, radii and colours are pushed into Niagara array parameters, so any particle effect can read the structure without custom shader work.
- **Colour schemes**: element (CPK), chain, secondary structure, B-factor, and the AlphaFold pLDDT confidence palette.

## Quick Start

1. Enable the plugin. It pulls in ProceduralMeshComponent, Niagara and MassGameplay, all of which ship with the engine.
2. Drop a **MolecularStructureActor** into a level.
3. Set **StructureFilePath** to a `.pdb` or `.cif` file. Relative paths resolve against the project directory, so `Plugins/MolecularForge/Demo/1EMA.pdb` works out of the box.
4. Pick a **Representation** and a **ColorScheme**. That is the whole setup.

To fetch instead of load, use the Blueprint node **Fetch Structure** with a PDB ID (`1CRN`) or a UniProt accession (`P69905`, resolved through the AlphaFold database).

## Example Levels

Under `Content/MolecularForge/Maps/`:

| Level | Shows |
|-------|-------|
| `L_MF_Showcase` | GFP (1EMA), 1771 atoms, CPK colours |
| `L_MF_Comparison` | Crambin (1CRN) in all five representations at once |
| `L_MF_Mesoscale` | 780 molecules diffusing and binding on Mass |

Every level is generated by a Python script under `Tools/`, not hand-placed, so it can be rebuilt after any change:

```powershell
UnrealEditor-Cmd.exe <uproject> -run=pythonscript `
  -script="<Plugin>/Tools/build_showcase_level.py" -unattended
```

## Modules

| Module | Contains |
|--------|----------|
| `MolecularForgeRuntime` | Parsers, structure data, DSSP, selection language, measurements, DCD |
| `MolecularForgeRender` | Atom, bond, cartoon and surface components; structure actor; trajectory player |
| `MolecularForgeWeb` | RCSB and AlphaFold fetching, identifier validation, on-disk cache |
| `MolecularForgeNiagara` | Structure to Niagara array parameters |
| `MolecularForgeMass` | Mesoscale spawner, diffusion and binding processors, staggered renderer |

## Limits

Atoms are drawn as real sphere geometry through instanced static meshes. That is comfortable for structures of a few thousand atoms; it is not a renderer for a whole virus capsid. Trajectory support is DCD only — XTC needs a compression library and is not included. The mesoscale layer models diffusion and binding; it is not a molecular-dynamics force field and does not claim to be one.

## Data Licences

The demo structures (Crambin 1CRN, GFP 1EMA, human deoxyhaemoglobin 4HHB) come from the RCSB Protein Data Bank. Structures you download at runtime carry the licence of their source — AlphaFold models are CC-BY 4.0 and naming the source is a condition of that licence. The plugin supplies the attribution string on every loaded structure as `Meta.Attribution`.
